# assets/

Hand-made files only: Excalidraw drawings, screenshots, exported images.

> [!info] Plugin figures do **not** live here
> The diagrams in `solutions/` are `tikz`, `desmos-graph`, `smiles` and `math` blocks that
> Obsidian renders live — no image files are produced, and nothing goes stale. See
> [docs/PLUGIN-FIGURES.md](../docs/PLUGIN-FIGURES.md).

```
assets/
├── chemistry/     ← optional: exported structures (PNG/SVG) from a browser editor
└── diagrams/      ← optional: Excalidraw drawings, imported screenshots
```

Embed anything here the usual way: `![[assets/diagrams/my-figure.png]]`.
Keep Excalidraw drawings as `.excalidraw.md` files so they stay editable.
